## Project Overview

Build a **production-ready real-time web application for discovering, analyzing, simulating, and manually executing DEX-to-DEX arbitrage opportunities using live on-chain blockchain data**.

This is a **WEB APPLICATION**, not a terminal, CLI, command-line tool, or static results dashboard.

When the application is running in a browser, the user must be able to see the real scanner operating in real time:

- RPC provider health
- current blockchain block
- network status
- pool discovery
- pools being monitored
- routes being evaluated
- quotes being refreshed
- scanner activity
- opportunities being detected
- profitability calculations
- RPC requests/health
- errors and retries
- opportunity freshness
- execution readiness
